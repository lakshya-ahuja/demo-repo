# 📌 About The Project

**LifeDrop** is a blood donation camp management website developed
as part of an academic Internet Programming project.

The primary objective of LifeDrop is to provide a simple and
accessible platform where potential blood donors can explore
the donation process, check preliminary eligibility, register
their details and view donation appointment slots.

The website aims to simplify the initial stages of blood donation
camp participation through an organised and user-friendly interface.

LifeDrop focuses on making the donation process easier to understand
while encouraging awareness about the importance of blood donation.

The project is developed entirely using **HTML, CSS and JavaScript**,
with an emphasis on fundamental front-end web development concepts.

---

# 🎯 Project Objectives

The main objectives behind developing LifeDrop are:

- To create a simple and user-friendly blood donation platform.
- To provide a structured donor registration process.
- To introduce a preliminary donor eligibility questionnaire.
- To display available donation appointment slots.
- To visually represent blood collection progress.
- To apply fundamental HTML, CSS and JavaScript concepts
  in a practical project.
- To understand how different front-end technologies work together
  to create an interactive website.

# ✨ Main Features

LifeDrop includes four primary features designed to make
the donation process straightforward.

## 1. 📝 Donor Registration

A dedicated registration form allows interested donors to submit
their basic information.

The form collects details such as:

- Full Name
- Age
- Contact Information
- Blood Group
- Other relevant registration details

The registration interface is designed to make the process
simple and convenient for potential donors.

## 2. ✅ Preliminary Eligibility Check

Before proceeding with registration, users are presented with
a short eligibility questionnaire.

The questionnaire provides a preliminary indication of whether
a user can proceed to the registration stage.

This creates a structured registration flow:

**Eligibility Check → Registration Form**

The feature demonstrates basic form handling and conditional
display of website elements.

*Note: This is an educational demonstration, not a medical
eligibility assessment. Actual blood donation eligibility
must be determined by qualified medical personnel.*

## 3. 📅 Appointment Slots

LifeDrop provides an appointment slot interface where users
can explore available donation time slots.

This feature demonstrates how an appointment selection interface
can be organised within a blood donation camp management website.

It aims to make the donation process more structured and convenient.

The displayed slots are part of the front-end demonstration
and are not connected to a live booking system.

## 4. 📊 Collection Progress Meter

A visual progress meter represents the progress of a blood
donation camp towards its collection target.

It provides visitors with a quick overview of the camp's
collection progress.

The feature makes use of a visual progress indicator to present
information in a simple and understandable format.

# 🛠️ Technologies Used

LifeDrop is built using three fundamental web technologies.

### 1. HTML5

**Purpose: Structure and Content**

HTML is used to create the basic structure of the website.

It defines:

- Website sections and headings.
- Navigation elements.
- Registration forms.
- Input fields and buttons.
- Different content elements.

### 2. CSS3

**Purpose: Styling and Layout**

CSS is responsible for the visual appearance of LifeDrop.

It is used for:

- Page layouts and alignment.
- Colour combinations.
- Typography.
- Spacing and padding.
- Buttons and form styling.
- Overall visual consistency.

The website follows a colour palette consisting of:

- Coral
- Beige
- Cream
- Teal
- Navy Blue

### 3. JavaScript

**Purpose: Basic Interactivity**

JavaScript is used wherever basic functionality is required.

Its applications include:

- Basic form validation.
- Eligibility questionnaire interactions.
- Displaying registration elements conditionally.
- Handling simple user interactions.
- Updating interface elements.

The JavaScript implementation is intentionally kept
beginner-friendly and limited to fundamental concepts.
